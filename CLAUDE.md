# mcp_assist_3d

## TTS assets

To migrate a map (mat and terrain) from the TTS mod, read `scripts/README.md` first. It describes `scripts/migrate-terrain.mjs`, the AssetRipper steps, and the TTS rules that were measured. `ASSETS.md` lists what the TTS cache has.

## Verifying changes

Do not open the app in a browser (playwright-cli, dev server, screenshots) to check a change unless I ask for it in that message. `vite build` to catch errors is fine. I check the result in the browser myself.
